# EVACUAIDE — Unity VR Earthquake Simulation Assets

Complete asset package for **MANILA INNOVATIONS TOWER**, a 5-floor Philippine
office building for a Meta Quest earthquake evacuation VR simulation.

All assets are generated by scripts, so the whole package is reproducible and
QA-checkable. Everything here has been **generated and validated** (see
`QA_REPORT.md`).

## How to regenerate everything (this machine)

Blender 5.2 is installed. From a PowerShell prompt:

**1) Generate all FBX (building, hazards, equipment, animations):**
```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --python "Scripts\run_all.py"
```

**2) Generate the SVG maps (pure python, uses Blender's bundled python):**
```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\5.2\python\bin\python.exe" "Scripts\phase5_evac_maps.py"
```

**3) Run QA (writes QA_REPORT.md, exits non-zero on any failure):**
```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\5.2\python\bin\python.exe" "Scripts\qa_validate.py"
```

> Run these from inside the `Evacuaide_Assets_Rhenmart` folder, or use full
> paths to the scripts. Output paths are resolved relative to each script, so
> assets always land in the correct sibling folders.

## Unity handoff

1. Install Unity 6 LTS (or 2022.3 LTS) via Unity Hub. Target platform: Android (Quest).
2. Create/open your Unity project. Copy the whole `Unity/` contents and the
   asset folders into `Assets/Evacuaide/` (see layout in `Unity/EvacuaideImporter.cs`).
3. Install the packages listed in `Unity/packages-to-install.md` (XR Interaction
   Toolkit, OpenXR, XR Management, Vector Graphics).
4. Menu → **Evacuaide → Import & Build Scene**. This sets FBX import settings,
   builds the scene, and adds XR grab components to equipment.
5. Attach `HazardStateController` to each hazard instance and call
   `SetTriggered(true)` from your earthquake event to swap pre → post state.

## Asset details

### Hazards (pre/post earthquake in one FBX)
Each hazard FBX contains `<Name>_Pre` and `<Name>_Post` meshes.
`HazardStateController` toggles them at runtime. `ElectricalPanel_Spark` also
ships a `SparkPoint` node to anchor a spark particle effect.

### Equipment (VR grab scale)
Flashlight, EmergencyBag, FirstAidKit, FireExtinguisher — each with a `GrabPoint`
empty at the natural grip for XR Interaction Toolkit socketing. Flashlight also
has a `LightAnchor` for a spotlight.

### Evacuation maps (SVG, bilingual)
Filipino + English room labels, green exit routes with arrowheads, red hazard
markers, blue stairwells, yellow assembly areas, per-floor legend. Import via
Vector Graphics for a world-space UI canvas per floor.

### Evacuation animations (baked FBX)
Per floor: a glowing green arrow travels room → stairwell → ground exit with a
following camera. 30 fps, 5 s (150 frames), baked keyframes → Unity generic
Animation Clip.

## QA / loop engineering
`Scripts/qa_validate.py` checks presence, FBX headers, expected node names
(pre/post states, grab points, arrows) and SVG well-formedness + palette. It
writes `QA_REPORT.md` and returns a non-zero exit code on any failure, so it can
gate a build. Current status: **87/87 checks passing**.
